# MATLAB-Projects-Research
Welcome to my MATLAB repository. This space contains a collection of academic and independent research projects focused on statistical learning, linear algebra, and data visualization.

The primary goal of these projects is to build a deep, foundational understanding of machine learning models by implementing them strictly from scratch, without relying on high-level pre-packaged toolboxes. By writing the core mathematical logic for algorithms like K-means, K-medoids, Principal Component Analysis (PCA), and Singular Value Decomposition (SVD), these projects demonstrate a rigorous approach to handling high-dimensional data, extracting latent features, and optimizing model robustness.

Key Technical Focus Areas:

Algorithm Implementation: Coding core machine learning logic from the ground up.

Dimensionality Reduction: Compressing complex data (like facial imagery) while retaining maximum variance.
